Realtime raytracer

My undergraduate dissertation involved creating a realtime ray tracer using NVIDIA CUDA, OpenGL and GLFW.
The program takes an array of pixels and turns it into a scene using only ray tracing techniques with the GPU through CUDA. OpenGL/GLFW are then used to create a window and project those pixels onto a texture which is displayed in the window
